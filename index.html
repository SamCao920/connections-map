                Sync with GitHub

                Your contacts are saved as one JSON file in a private repo you own. The token stays in this browser and is only sent to GitHub.

                How to make a token
                1. Create a private repo for your data, e.g. connections-data.
                2. Go to GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
                3. Repository access: Only select repositories, pick your data repo.
                4. Permissions: Contents → Read and write. Nothing else.
                5. Paste it here. Repeat on each device you use.

                Trip notifications

                Get a notification from this site when you book a trip to a city where people on your map live. Turn it on separately on each device.

                One-time setup. Create a signing key. Your browser makes it; it is never sent anywhere except where you paste it.

                1. Copy this private key:
                2. Open your data repo’s Actions secrets, name the secret VAPID_PRIVATE_KEY, paste, and save.
                3. Come back and tap “Turn on for this device”.

                This key is shown only now. If you lose it, create a new one; every device then has to turn notifications on again.

                Import from Apple Contacts

                Export a vCard first. Mac: select people in Contacts → File → Export → Export vCard. Or iCloud.com → Contacts → select → Export vCard. Then choose who to add.
